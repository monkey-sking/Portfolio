# Portfolio Website

上岸的鱼 · Fish Ashore 个人作品集网站

## 技术栈

- 纯静态 HTML/CSS/JS
- Glassmorphism 设计风格
- 中英双语支持

## 本地预览

```bash
# 使用任意静态服务器
npx serve .

# 或 Python
python -m http.server 8000
```

然后访问 http://localhost:8000

## 部署

可直接部署到：
- GitHub Pages
- Netlify
- Vercel
- 任意静态托管服务
